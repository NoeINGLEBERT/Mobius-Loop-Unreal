# Alice: The Rabbit Hole Loop (Unreal Engine)

## Overview
This Unreal Engine project is an **adaptation of Alice: The Rabbit Hole Loop**, preserving the same narrative foundation and looping structure inspired by **Loop Hero** and **Alice in Wonderland**.

The player still embodies Alice, trapped in a distorted rabbit hole, seeking escape while navigating a world governed by illogical rules and unstable minds.

## Gameplay
The core structure remains intact:
- Loop-based progression
- Narrative exploration
- Interaction with iconic NPCs

However, due to time constraints, some systems have been **simplified** compared to the Unity version.

## Differences from the Unity Version
- The advanced **word-construction system using letter cards** is replaced by:
  - More **traditional quest logic**
  - **Dialogue-based progression** between NPCs
- Environmental interactions are less systemic.
- Animations are more minimal and primarily functional.

## Technical Architecture
- The codebase includes **unused and placeholder elements**, intentionally kept to:
  - Allow future implementation of the full word-based systems
  - Facilitate feature parity with the Unity version
- The project is structured for scalability and future expansion.

## Project Status
A **functional but incomplete version**, designed as a base for further iteration rather than a final experience.
